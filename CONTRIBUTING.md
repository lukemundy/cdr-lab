# Contributing

This repository accepts issues, but not pull requests. A pull request from outside the repository is closed with no review.

- To report a defect or to ask a question, open an issue. Give the commit, the steps and the result that you expected.
- To report a vulnerability, follow [SECURITY.md](SECURITY.md). Do not open an issue.

The code has no open-source licence. See the [Licence](README.md#licence) section of the README.
