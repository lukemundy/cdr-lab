# Security

cdr-lab is a simulation of the Consumer Data Right for tests and learning. It is not a production service, and it has no real consumer data.

## Report a vulnerability

Do not open a public issue for a vulnerability. Use [private vulnerability reporting](https://github.com/lukemundy/cdr-lab/security/advisories/new) on GitHub.

Give the affected component, the commit, the steps to cause the problem and its effect. You get a reply when the report has been examined. There is no bug bounty.

## Scope

- The code in this repository and the images that CI publishes from `main`.
- The GitHub Actions workflows of this repository.

A shortcut in [`docs/production-gaps.md`](docs/production-gaps.md) is known, and acceptable in the lab only. It is not a vulnerability.
